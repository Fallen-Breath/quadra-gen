# Quadra Gen 功能说明

[English](features.md) | 中文

## 1. 项目定位

Quadra Gen 是一个 Fabric 世界生成 Mod，在同一个维度内提供四块可独立配置的地形环境。

核心模型：

- 以 X/Z 坐标轴为边界，把主世界或下界划分为四个象限，原点固定于 `(0, 0)`；
- 每个象限选用一种地形类型：当前维度的原版自然地形，或由固定群系与固定方块层构成的超平坦地形；
- 两类地形都可以关闭实际内容生成，得到只保留地形语义的空区。

四个象限仍属于同一个原版维度。它们共享时间、天气、难度、游戏规则、世界边界、玩家列表与实体数量上限；红石、流体、方块事件、POI、袭击、实体 AI 与传送门也不因象限而隔离。Quadra Gen 改变的只有新区块的生成方式，以及与地形类型直接相关的查询结果。

安装要求：

- 多人游戏：只需在服务端安装，原版客户端可直接连接，无需安装任何客户端内容；
- 单人游戏：通过 integrated server 运行同一套功能，默认关闭，需要在配置中显式开启。

## 2. 作用范围

适用维度为主世界与下界，两者可以分别启停。末地、数据包自定义维度以及其他 Mod 添加的维度不受影响。

受管理的维度必须使用对应版本的原版自然地形作为底层世界类型：主世界使用原版主世界 Noise 地形，下界使用原版下界 Noise 地形。底层类型不是原版 Noise 的生成器不会启用本功能；第三方在原版 Noise 类型上扩展的生成器不作兼容保证。

功能是否生效由以下条件共同决定，任一条件不满足时 Mod 完全不介入该维度：

1. Mod 总开关已启用；
2. 单人存档下，单人游戏开关已启用；
3. 对应维度的独立开关已启用；
4. 该维度使用受支持的原版自然地形。

配置只在 Mod 启动时读取一次，不支持热重载。

以原版超平坦世界类型创建的存档不会被自动纳入管理，也不会被自动转换，详见第 13 节。

## 3. 象限划分

象限原点固定为 `(0, 0)`，不可平移或旋转。X 或 Z 等于零的坐标归入正侧：

| 配置键 | 坐标范围 |
| --- | --- |
| `x_positive_z_positive` | `x >= 0, z >= 0` |
| `x_negative_z_positive` | `x < 0, z >= 0` |
| `x_negative_z_negative` | `x < 0, z < 0` |
| `x_positive_z_negative` | `x >= 0, z < 0` |

两条坐标轴与区块边界重合，因此每个区块完整属于一个象限，单个区块内部不会拼接两种基础地形。

主世界与下界各自拥有一套完整的四象限配置，同一坐标在两个维度中可以使用不同的群系、方块层或地形模式。

## 4. 四种地形模式

象限由两个属性定义：

- `generator`：`noise` 表示原版自然地形，`flat` 表示超平坦地形；
- `clear_generated_content`：是否阻止该地形实际生成内容。

两个属性组合为四种模式：

| 模式 | 群系 | 理论地形 | 结构信息 | 新区块实际内容 |
| --- | --- | --- | --- | --- |
| Noise | 当前维度的原版自然群系 | 原版自然地形 | 原版结构 | 完整的原版地形、结构、装饰与世界生成生物 |
| Noise clear | 当前维度的原版自然群系 | 原版自然地形 | 保留原版结构信息 | 不生成地形、结构内容、装饰或世界生成生物 |
| Flat | 配置的固定群系 | 配置的固定方块层 | 不产生属于该象限的结构 | 只生成配置的方块层 |
| Flat clear | 配置的固定群系 | 配置的固定方块层 | 不产生属于该象限的结构 | 不生成方块层或其他世界生成内容 |

本节的“理论地形”指世界生成器对指定坐标给出的高度与方块列结果，用来描述相应地形类型的生成依据，与区块中实际存在的方块无关。clear 阻止内容落地，但不改变所属地形类型的理论结果。

### 4.1 Noise

Noise 象限保持当前维度的原版自然生成：群系、地形、洞穴、含水层、地表、结构、装饰与世界生成生物全部由原版规则决定。

主世界与下界各自使用本维度的自然生成规则。下界不会因为同样使用四象限模型而获得主世界的高度、海平面、天空或生物行为。

### 4.2 Noise clear

Noise clear 是保留自然世界语义的空区：新区块仍写入原版自然群系，并保留自然地形的理论高度、理论方块列与结构信息，但不生成自然地形方块、结构内容、装饰或世界生成生物。

保留的结构信息继续参与原版机制判定，例如结构范围刷怪、地图与已探索结构计数，与区块当前是否为空无关。

### 4.3 Flat

Flat 象限由固定群系和一组有序的方块层构成。

- 第一层从当前维度的最低可建造高度开始，不提供单独的起始高度配置。同一份配置用于不同 Minecraft 版本或不同维度时，实际起始 Y 随该版本、该维度的世界高度变化。
- 每层包含方块 ID 与正整数厚度，各层厚度总和不得超过当前维度的可建造高度。
- 层配置表达的是方块的默认状态，不能指定朝向、含水等方块状态属性。
- 层的放置遵循对应版本原版超平坦生成器的规则，包括原版安排在后续生成环节放置的层（例如玻璃这类非完整实心方块的层）。这些层同样会落地，高度查询也不会因为放置顺序而缺失它们。
- Flat 象限不生成原版超平坦世界的结构、湖泊与普通群系装饰。
- 空层列表是合法配置，表示完全为空的 Flat，它也不会生成原版 Void 预设附带的初始平台。
- 高度与方块列查询以完整配置层为准，与区块的生成进度无关。

### 4.4 Flat clear

Flat clear 保存配置群系与完整理论层，但不放置任何一层，适用于需要固定群系与固定理论高度、同时要求新区块完全为空的场景。

`clear_generated_content` 只控制生成内容是否落地。它不改变群系、理论高度与海平面语义，也不会把 Flat clear 变成 Noise clear。

## 5. Clear 的作用边界

clear 在生成流程中抑制内容产出，不会先完整生成再删除。因此清空区块不会附带产生并移除大量方块、方块实体、流体刻或实体。

clear 不具备追溯清理能力。下列内容不因为所在象限启用了 clear 而被删除或停止：

- 已完成区块中的方块与实体；
- 玩家或命令放置的内容；
- 运行时产生的实体，包括自然刷怪、刷怪笼、繁殖等来源；
- 红石、流体、随机刻、计划刻与方块事件；
- 从相邻区域跨入的实体和运行时变化。

修改配置同样不会重塑已完成区块。配置变更只影响此后尚未执行相应生成过程的区块，以及按当前配置回答的世界级理论查询。

## 6. 群系与地形查询

### 6.1 区块群系

区块写入其所属象限应有的真实群系：Noise 两模式写入原版自然群系，Flat 两模式写入配置群系。因此玩家进入已生成区块后，天气、自然刷怪等读取区块群系的原版系统可以取得与象限一致的结果。

### 6.2 群系定位

对尚未生成的坐标定位群系时，结果按象限给出，而不是整体按底层 Noise 世界给出。搜索可以同时覆盖自然群系与仅存在于 Flat 配置中的群系，并保持对应版本原版的搜索顺序与采样方式。

| Minecraft 版本 | 行为 |
| --- | --- |
| 1.14.4–1.15.2 | 不具备可供扩展的服务端群系定位入口，Quadra Gen 不额外提供命令 |
| 1.16.5–1.18.2 | 按对应版本的二维、最近优先规则搜索 Noise 与 Flat 群系 |
| 1.19.4 及以上 | 按对应版本的三维搜索规则查找 Noise 与 Flat 群系 |

在每个采样点上，Flat 两模式使用配置群系，Noise 两模式使用自然群系。clear 不影响群系定位的结果。

### 6.3 高度与方块列查询

- Noise 与 Noise clear 返回自然地形的理论结果；
- Flat 与 Flat clear 返回配置层的理论结果；
- clear 不会把理论结果变成全空气；
- 空层 Flat 的理论高度为对应版本的最低可建造高度。

理论地形与区块的实际高度图可以不一致：前者是相应地形类型的生成依据，后者描述世界中真实存在的方块。

## 7. 结构与结构定位

结构信息的保留范围：

- Noise：完整保留并生成原版结构内容；
- Noise clear：保留结构的位置、范围和关联信息，不放置结构方块、战利品容器、刷怪笼或相关世界生成生物；
- Flat 与 Flat clear：不产生属于自身的结构，这些象限中的坐标不会仅仅因为底层世界是 Noise 而被当作有效结构来源。

结构定位以实际保留的结构信息为准：

- Noise 结构以及 Noise clear 中保留的结构可以被定位；
- Flat 象限不会报告一个并未在该处建立的结构；
- 末影之眼、探索地图、海豚寻宝与村民地图交易的结构定位结果和结构定位命令一致。

坐标轴附近的 Noise 结构可能部分延伸进相邻象限。相邻区块会保留识别这段结构所需的关联信息，因此结构范围刷怪、地图与已探索结构计数不会在轴上被生硬切断。这种邻界关联不等价于 Flat 象限启用了结构生成。

## 8. 象限边界

基础地形具有严格边界：Flat 或 clear 区块不生成 Noise 基础地形、地表或洞穴，普通 Noise 区块（`generator` 为 `noise` 且未启用 clear）也不会把 Flat 或 clear 区块当作洞穴来源。洞穴不会从较远的不相容象限持续穿入普通 Noise 区域。

结构与装饰遵循原版的邻区生成范围，不做逐方块硬裁切。坐标轴附近可能出现树木边缘、结构边角等有限的跨界内容，其范围由对应版本的原版生成行为决定，也不会形成从远处持续污染其他象限的通道。

Minecraft 26.2 的自然地表生成会参考目标区块及其周围区块的实际群系，轴边的 Noise 区块可能因此受到相邻 Flat 象限群系的局部影响（仅当该群系同时属于当前维度的自然群系时）。其他目标版本没有这一行为。

运行时世界状态不存在象限墙：实体、玩家方块、流体、爆炸、红石、POI、袭击与传送门都可以跨过坐标轴。

## 9. 海平面语义

### 9.1 世界生成期间

Noise 两模式始终使用当前维度的原版自然海平面，使自然地形、含水层、地表与结构计算保持一致。Flat 两模式不进入这些 Noise 生成流程，只按对应版本的原版超平坦规则处理配置层，不依据海平面自动补水。clear 不改变海平面语义。

### 9.2 运行时

同一维度内的运行时海平面只在判断带有明确 X/Z 坐标时按象限区分。无坐标的维度级查询继续返回底层 Noise 值，不根据最近玩家、当前任务或其他隐含状态推断象限。

| Minecraft 版本 | 运行时行为 |
| --- | --- |
| 1.14.4–1.21.1 | 原版运行时世界接口的海平面是维度级固定值，不区分 Noise 与 Flat；相关判断保持该原版值 |
| 1.21.3 及以上 | 服务端中带坐标的降水与天气、结冰与积雪、水生生物生成、部分水生生物 AI、幻翼生成与幻翼 AI 按所在象限使用 Noise 或 Flat 海平面 |
| 1.21.11 及以上 | 在上一行基础上，鹦鹉螺（Nautilus）的生成高度判断同样按象限处理 |

在 1.21.3 及以上的目标版本中，原版 Flat 的海平面为 `-63`；主世界与下界的 Noise 海平面来自各自的自然生成设置，通常为 `63` 与 `32`。

### 9.3 客户端可见性

原版客户端只接收一个维度级海平面，Quadra Gen 不扩展网络协议。因此服务端中带坐标的判定可以按象限工作，而客户端天气表现以及直接读取维度级海平面的第三方逻辑仍可能得到 Noise 值。

## 10. 生物生成

### 10.1 世界生成期间

Noise 象限保留原版区块生成期间的生物生成；Noise clear、Flat 与 Flat clear 不在新区块的生成过程中放置生物。

### 10.2 运行时自然刷怪

运行时自然刷怪仍由原版统一管理，并在同一维度内共享一套数量上限。候选结果取决于区块保存的群系、有效结构范围、实际方块、流体、光照与高度图：

- Noise：与普通原版自然世界一致；
- Noise clear：完全为空时通常不存在合法的生成位置，玩家搭建环境后可依据自然群系与结构范围刷怪；
- Flat：使用配置群系与实际铺设的表面；
- Flat clear：使用配置群系，但仍必须满足真实世界中的原版生成条件。

### 10.3 特殊事件与版本差异

幻翼、巡逻队、猫、村庄围攻与流浪商人继续遵循对应版本的原版规则。空层、`minecraft:the_void` 或 clear 本身不会成为额外的幻翼禁用条件；`minecraft:the_void` 仍会通过原版群系规则阻止普通群系刷怪与流浪商人。

| Minecraft 版本 | 按象限处理的差异 |
| --- | --- |
| 1.14.4–1.15.2 | 原版超平坦世界不运行巡逻队与村庄围攻，史莱姆生成也带有超平坦世界特有的抑制（四次判定中仅一次继续）。Quadra Gen 在 Flat 象限中保持这些差异，Noise clear 仍按 Noise 类型处理 |
| 1.16.5 及以上 | 原版 Noise 与 Flat 主世界使用相同的特殊刷怪器集合，上述差异不再适用，能否生成由群系与实际环境决定 |

已有实体可以自由跨象限。Mod 不会因为实体进入另一种地形模式而删除、冻结或重新分类它。

## 11. 初始出生点

Quadra Gen 只调整新主世界第一次初始化时的出生选址。已有存档的出生点不会重算，下界不参与此功能。

选址规则：

- 若存在普通 Noise 象限，把原版出生搜索的中心移动到距离最近的普通 Noise 象限内部，再交回原版流程寻找具体的安全位置；
- 为避免搜索范围跨过坐标轴，1.14.4–1.17.1 在轴线处预留 16 个区块，1.18.2 及以上预留 5 个区块；
- 当前不把安全的非 clear Flat 象限作为次选。若不存在普通 Noise 象限，继续使用原版选择的搜索中心。

Mod 不为全空配置创建出生平台，也不输出专门的全空警告。最终出生位置下方若不存在无流体且上表面完整的碰撞面，奖励箱会被关闭，避免在明显不安全的位置尝试生成；其余出生搜索规则仍由对应版本原版决定。

## 12. 配置功能

配置文件位于 `config/quadragen/config.json`，当前 schema 版本为 `1`。配置文件不存在时，Mod 会创建默认配置。各字段的取值与默认值见[配置文档](config.zh.md)。

配置层次：

```text
全局配置
├── schema_version
├── enabled
├── enabled_in_singleplayer
├── overworld
│   ├── enabled
│   └── 四个象限
└── nether
    ├── enabled
    └── 四个象限
```

每个象限必须声明 `generator` 与 `clear_generated_content`；选择 `flat` 时必须同时提供固定群系及完整层列表，选择 `noise` 时不得携带 Flat 配置。

配置采用严格校验：

- 拒绝未知字段、缺失字段与错误的数据类型；
- `schema_version` 必须等于当前版本；
- 四个象限缺一不可；
- `generator` 只能是 `noise` 或 `flat`；
- 群系与方块必须是有效且已注册的 ID；
- 每层厚度必须是正整数；
- 总层高不能超出对应维度的可建造范围。

群系、方块与层高需要结合实际维度校验，因此校验只在相应维度启用且世界类型受支持时完成。被关闭或不受支持的维度不会解析其中的 Flat 内容。

默认配置启用总开关与两个维度，关闭单人游戏支持，两个维度使用相同的模式布局：

| 象限 | 默认模式 | 主世界配置 | 下界配置 |
| --- | --- | --- | --- |
| `(+X,+Z)` | Noise | 原版主世界自然地形 | 原版下界自然地形 |
| `(-X,+Z)` | Noise clear | 保留主世界自然语义的空区 | 保留下界自然语义的空区 |
| `(-X,-Z)` | Flat | `minecraft:the_void`，空层 | `minecraft:the_void`，空层 |
| `(+X,-Z)` | Flat | `minecraft:plains`，一层白色染色玻璃 | `minecraft:nether_wastes`，一层白色染色玻璃 |

Minecraft 1.14.4–1.15.2 的下界默认群系 ID 是当时使用的 `minecraft:nether`。

## 13. 存档与既有世界

### 13.1 数据格式

Quadra Gen 生成的区块继续使用原版区块、群系、结构与实体数据格式。存档中仍记录对应维度的原版 Noise 世界类型，不要求使用 Quadra Gen 专属的生成器、群系或区块数据。

因此：

- 只有新区块以及尚未完成相关生成过程的区块会受影响；
- 已完成区块不会因安装、卸载或更改配置而被主动重写；
- 带 Mod 生成的完整区块可以由同版本原版读取；
- 移除 Mod 后，已有区块保持原状，新区块恢复为当前维度的普通 Noise 生成；
- 移除 Mod 后，未完成的区块可能由原版 Noise 流程继续完成，从而形成局部混合；
- 当前配置仍会影响未生成坐标的群系、理论地形与海平面查询，但无法还原旧区块生成时使用的历史配置。

### 13.2 旧区块升级

Minecraft 1.18.2 及以上遇到原版正在升级或补全的旧区块时，优先执行完整的原版升级流程，不按当前象限重新铺设或清空，以保留原版旧基岩处理、地形衔接与边界更新。

### 13.3 原版超平坦存档

以原版 Flat 世界类型创建的旧存档不受直接支持。若希望在保留既有超平坦设计区的同时使用 Quadra Gen，需要先停止服务、完整备份，并在离线状态下把目标维度的世界类型转换为同版本的原版 Noise。Mod 本身不会修改存档记录的维度设置，也不执行这项转换。

## 14. 支持版本

当前项目覆盖以下 Minecraft 版本：

- 1.14.4、1.15.2、1.16.5、1.17.1、1.18.2、1.19.4；
- 1.20.1、1.20.2、1.20.4、1.20.6；
- 1.21.1、1.21.3、1.21.4、1.21.5、1.21.8、1.21.10、1.21.11；
- 26.1.2、26.2、26.3。

除下表列出的版本差异外，各版本提供相同的四象限配置模型与地形语义；世界高度、下界群系名称、群系定位方式、运行时海平面与部分特殊刷怪行为随 Minecraft 自身变化，Quadra Gen 以对应版本的原版 Noise 或 Flat 表现为准。

| 差异项 | 适用版本 | 说明 |
| --- | --- | --- |
| 世界高度与最低可建造高度 | 随原版变化 | 决定 Flat 层的起始 Y 与层高上限 |
| 下界默认群系 ID | 1.14.4–1.15.2 | 使用当时的 `minecraft:nether` |
| 群系定位 | 1.14.4–1.15.2 无；1.16.5–1.18.2 二维；1.19.4 及以上三维 | 见 6.2 |
| 初始出生预留区块数 | 1.14.4–1.17.1 为 16；1.18.2 及以上为 5 | 见第 11 节 |
| 运行时海平面 | 1.21.3 及以上按象限区分；1.21.11 及以上额外覆盖鹦鹉螺 | 见 9.2 |
| 地表生成的邻区群系参考 | 26.2 | 见第 8 节 |
| 特殊刷怪器与史莱姆抑制 | 1.14.4–1.15.2 | 见 10.3 |
